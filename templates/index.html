Q: What was your PhD about?

When data is sent over the Internet, it has to travel through noisy communication channels like cables. Along the way, it gets corrupted by physical phenomena like earthquakes and sharks, as well as more mundane things like faulty routers. To overcome this, the computer people use a technology called error correction codes, which add redundancy to a message. Error correction algorithms exploit the redundancy to identify and fix errors. I was researching such algorithms.

An emoji example! You take your data 📚, encode it using a repetition code 📚📚📚, send it through a communication channel 🌐, the channel introduces errors 📚❌📚, and the receiver uses a decoding algorithm to identify the errors and recover the original message 📚.
