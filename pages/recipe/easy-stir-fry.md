name: Easy stir fry
source: me

### Ingredients
* noodles of some description
* tofu
* garlic
* vegetables (pepper, mushroom, bok choy, red cabbage, baby corn, pea pods, etc.)
* soy sauce (vibes-based amount)
* other spices (usual suspects: chili flakes, ginger, ...)

### Instructions
1. Fry tofu with garlic in a wok, maybe add some soy sauce & spices.
2. Add other vegetables as appropriate so that the timings work out.
3. Add noodles.
4. Add a shitload more soy sauce.
